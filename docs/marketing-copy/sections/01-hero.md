### New set (2026-08-20). Composer reframe, three variants

Eyebrow for all three: The brand and taste layer for agents.

Trust chips for all three: Local run · No account · No telemetry

#### Variant 1. You already wrote it down

**Title.** Give your agent the rules you already wrote down.

**Subtitle.** Your agent has never read your brand guide, so it guesses. Paste the guide, an article, or a repo, and get back rules it can follow.

**Body.** Tastefield writes each rule with the source line it came from, so you can check it before you use it. Keep the ones that are right and drop the rest. Add the result to Claude Code, Codex, or Cursor, and it flags work that is still off-brand.

**CTAs.** Compose from a source · Start from a role

Why this one. The title carries the addressable-market boundary inside the sentence, because "already wrote down" excludes the visitor who needs a brand invented. It reads the same to a creative director with a guide and to a developer with a repo, which is the job the fold now has. The subtitle names the failure state in the first clause, which is the copy mechanic already adopted.

#### Variant 2. The mechanism

**Title.** Compile what you already wrote into rules your agent can follow.

**Subtitle.** Paste an article, a brand guide, a SKILL.md, or a repo. Tastefield returns a short list of restraints, each one quoting the line it came from.

**Body.** Every restraint shows the decision, the reason, and the quoted source, so nothing arrives as a guess. The run happens on your machine and needs no account. Install the result in Claude Code, Codex, or Cursor to keep checking the work your agent writes.

**CTAs.** Compile my rules · Start from a role

Why this one. It leads with the verb the product actually performs, and the subtitle does the generalizing work by naming four sources in one line. Cost: "compile" needs a beat of explanation for the creative half of the audience, and the source list reads as a feature list. Use it if the fold has to argue breadth before it argues value.

#### Variant 3. The desk it happens at

**Title.** Your brand guide is written down. Your agent is still guessing.

**Subtitle.** Paste the guide, an article, or your repo. Tastefield turns it into rules your agent can follow, then checks the work that comes back.

**Body.** The rules come from your own words, with the source line attached to each one, so you can see where every rule was decided. Review the list and keep what fits. Then add it to Claude Code, Codex, or Cursor and stop correcting work a checker can catch.

**CTAs.** Compose from a source · See what it catches

Why this one. It is the warmest of the three and the closest to how the reader would describe the problem out loud. Two risks to weigh before picking it. The title is two clauses of similar shape, which sits close to the isocolon ban, and the subtitle promises the check on the first screen while the check now lives at the end of the page.

*Recommendation: Variant 1.* It matches the recommended H1 in the architecture doc, it survives the FORBIDDEN patterns without an exception, and it says nothing the page does not deliver. Variant 2 is the fallback if the fold has to name accepted sources. Variant 3 needs a ruling on the title before it can ship.
