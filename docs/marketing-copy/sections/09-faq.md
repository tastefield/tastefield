### Subhead / body

**Can you guarantee a clean first pass?**  
No. Models are stochastic. Anyone who promises a clean first pass is selling something they cannot demo. Tastefield checks the output afterward and names which line broke which rule.

**How is this different from zeroheight?**  
zeroheight is where teams document a design system and serve that context to agents. Tastefield compiles rules from what is already in your repo and checks agent output against them. You can use both. A zeroheight read is on the roadmap (`Soon`). Tastefield does not replace their docs product.

**Does anything leave my machine?**  
Tastefield itself does not phone home. No account. No telemetry. Your coding agent may still call a model provider the way it already does.

**Which editors work today?**  
Claude Code, Codex, and Cursor. Codex is listed on the assumption a standard MCP client works. End-to-end IDE proof is still open.

**Do you replace Figma or zeroheight?**  
No. Those stay where your team decides. Tastefield reads in and checks agent output.
